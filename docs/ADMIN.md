# JMT TRAVELS — Administrative Operations Console

## 1. Overview

The Admin Console is located at `/admin` (`admin.html`) and provides staff and administrators with operational tools for managing visa clearing, tourism packages, customer records, payment transactions, and support inbox inquiries.

## 2. Core Modules

1. **Dashboard Metrics**: Real-time snapshot of Total Customers, Total Visa Applications, Action Needed Visas, Tour Reservations, and Open Support Tickets.
2. **Visa Application Desk**: Search, filter, inspect applicant details, stream private passport document uploads securely, update processing statuses (`SUBMITTED` → `DOCUMENT_REVIEW` → `APPROVED`), and log internal notes.
3. **Tourism CMS**: Manage Destinations, Categories, Packages (Title, Image, Summary, Price, Inclusions, Duration), and toggle publication states (`published`).
4. **Payment Operations**: Inspect transaction order IDs, payment status (`COMPLETED`, `FAILED`), payment provider, and initiate refunds.
5. **Support Inbox**: Manage customer support tickets, view conversation threads, dispatch staff replies, and close resolved tickets.
6. **Audit Trail**: Super Admins can inspect immutable audit logs recording every status change, document access, and system action.

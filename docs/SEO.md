# JMT TRAVELS — SEO & Search Engine Optimization Guide

## 1. Technical SEO

- **Clean URLs**: Semantic route structure (`/visa`, `/tourism`, `/contact`).
- **Sitemap**: Auto-generated XML sitemap served at `/sitemap.xml`.
- **Robots.txt**: Served at `/robots.txt`, directing crawlers to public pages and disallowing admin routes (`/admin`) and private document uploads (`/api/documents/`).
- **Structured Data**: JSON-LD schema.org `TravelAgency` and `Organization` metadata included in `index.html`.
- **Open Graph**: Metadata tags (`og:title`, `og:description`, `og:image`) configured for social sharing.
